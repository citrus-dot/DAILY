# DAILY · Design Spec: Focus Session + Weekly Trends

> 日期：2026-08-14
> 方向：专注 & 效率流（用户选定）
> 本轮范围：番茄钟（绑定打卡任务） + 周报 & 趋势折线
> 不在本轮：温柔提醒 / 系统定时推送、云同步、多设备、待办完成历史（todoLog，列为可选）

---

## 1. 背景与目标

**现状**：单文件 HTML 打卡工作台（本项目根目录的 `DAILY.html`），已具备 任务类别管理 / 今日打卡（进度环）/ 本月进度（热力图）/ 待办（斩击动画）/ 数据备份。数据存于 `localStorage` 键 `wb_daily_state`（**铁律：键名绝不改**）。

**目标**：
- 让「做一件事」和「记录进度」连起来——专注一段时间 → 自动给对应任务 +1。
- 提供近况可视化（趋势折线 + 本周小结），更贴近日常复盘，让工具不只是记录、也帮人「看见自己」。

---

## 2. 范围与非目标

| 在范围内 | 不在范围内（本轮） |
|---|---|
| 番茄钟（绑定「今日打卡」任务，结束自动 +1） | 温柔提醒 / 系统定时推送 |
| 周报 & 趋势（扩展「本月进度」视图） | 云同步 / 多设备 |
| 专注历史记录（供周报统计） | 待办完成历史 todoLog（可选，默认不做） |

---

## 3. 数据模型变更（仅新增字段，绝不改 `wb_daily_state` 键名）

```js
STATE.focusLog = [            // 专注历史，供周报统计专注时长
  { date:'YYYY-MM-DD', taskId:String, minutes:Number,
    startedAt:Number/*ms*/, endedAt:Number/*ms*/ }
]
STATE.pomoPref = {            // 番茄钟偏好
  duration:Number/*默认25*/, break:Number/*默认5*/, lastTaskId:String?
}
```

- **兼容性**：旧数据无这些字段时按空数组 / 默认值处理，旧读取逻辑零影响。
- 仅 **新增** `focusLog` / `pomoPref`，不重命名、不删除任何现有字段。

## 4. 番茄钟模块

### 4.1 入口
- 每张「今日打卡」任务卡加一个「专注」按钮（手绘计时 SVG 图标，禁用 emoji）。
- 点击按钮本体 → 以该任务为绑定对象启动一次专注（默认时长）。
- 按钮旁小箭头 → 展开时长菜单 **15 / 25 / 45 / 90** 分钟，选中写入 `pomoPref.duration` 并记忆下次默认。

### 4.2 悬浮常驻小环
- 组件挂到 `document.body`（**非视图内**），`position:fixed` 定位在**右下角**（避开底部 Tab 栏），**跨视图切换不丢**。
- 显示内容：绑定任务名 + 剩余 `mm:ss` + 圆形进度环 + `暂停` / `停止` 控件。
- 计时精度：**基于 `Date.now()` 差值**计算剩余（非朴素 `setInterval` 递减），切后台 / 锁屏也不漂移；每秒刷新显示，暂停记录已用时间。
- 模式：专注（focus）→ 休息（break）自动切换。

### 4.3 完成流程（focus 结束）
1. 停止计时，进度环播放「完成」动画。
2. 调用现有 `bumpRecord(taskId, +1)`（复用进度环弹性滑动 + 卡片整体回弹），实现「做→记」一体。
3. 系统通知：若已授权 `Notification`，发送「专注完成！<任务名> 已 +1」；**被拒 / 未授权 → 降级为应用内 toast + 视觉提示，不报错**。
4. 将本次会话写入 `STATE.focusLog` 并 `save()`。
5. 自动进入 **5 分钟短休息环**（可跳过）；休息结束发送通知「休息结束，继续加油」并收起组件。

### 4.4 取消 / 停止
- 点「停止」：不 +1、不写历史，干净退出并收起组件。

### 4.5 通知权限
- 首次启动专注时调用 `Notification.requestPermission()`；拒绝则全程走 toast 降级。

### 4.6 健壮性
- **切后台漂移**：时间戳差值法，不依赖累加计数。
- **刷新页面**：本轮默认——未完成的进行中会话刷新后丢失（可接受）；已完成的 +1 与历史不受影响。可选增强：把活动会话存 `sessionStorage` 以便恢复（列为可选，不强制）。
- **无障碍**：`prefers-reduced-motion` 下所有动画近似瞬时。

## 5. 周报 & 趋势（扩展「本月进度」视图）

### 5.1 布局
- 在「本月进度」视图**顶部**新增「趋势」区，其下新增「本周小结」卡；
- **保留**原有热力图 + 达标天数进度条（不破坏现有结构）。

### 5.2 近 30 天达标率折线
- 手写 SVG 折线（平滑 `path`），x = 近 30 天，y = 当日达标率 = 达标任务数 / 当日应打卡任务总数。
- 无任务日记为 **0**（折线落到底部，避免断点）；可选：hover 显示日期 + 比率的轻提示。

### 5.3 近 7 天专注分钟
- 手写 SVG 柱状（或折线），数据来自 `focusLog` 按日聚合；无数据日高度为 0。

### 5.4 本周小结卡（自动文案）
- 计算窗口 = 本周一 ~ 本周日（「本周」语义）。
- 文案示例：「本周共打卡 **X** 次 · 达标 **Y** 天 · 专注 **Z** 分钟；最活跃 **周三**；最长连续 **N** 天」。
- 数据来源：`records`（打卡次数 / 达标 / 连续天数）+ `focusLog`（专注分钟）。
- 待办完成数：需 `todoLog`，**本轮默认不做**（标注可选，若做需新增轻量日志）。

### 5.5 空态
- 无专注记录时，趋势区显示「开始你的第一次专注 ⏱」引导（SVG 图标，非 emoji）。

---

## 6. 视觉与一致性

- 复用现有 CSS 变量；图标全部 SVG-only（计时 / 播放 / 暂停 / 图表），**禁用 emoji**。
- 缓动统一 `cubic-bezier(.34,1.3,.5,1)`，与现有动效一致。
- `prefers-reduced-motion` 全局兜底。
- **单文件、零外部依赖**（不引入图表库；折线 / 柱状手写 SVG）。

---

## 7. 错误处理

| 场景 | 处理 |
|---|---|
| 通知被拒 / 未授权 | 降级为应用内 toast + 视觉提示 |
| 无任务 / 无专注历史 | 趋势区 / 小结卡显示对应空态 |
| 计时精度 | 时间戳差值，不受后台节流影响 |

---

## 8. 测试与校验

- **语法**：抽取 `<script>` 经 `node --check` 通过。
- **手动**：
  1. 今日打卡卡点「专注」→ 悬浮小环出现、可切视图、计时走。
  2. 专注结束 → 验证任务 +1（环滑动 + 卡片回弹）、系统通知（授权时）、`focusLog` 写入。
  3. 切到「本月进度」→ 趋势折线 / 专注柱状 / 本周小结随数据更新；无数据时空态正确。
- **维护铁律**：改动后同步 `progress.md`（新增迭代记录）+ `Technical-Documentation.md`（模块说明）+ 工作区级与项目级两份开发日志（`2026-08-14.md`）。
- **兼容性**：`wb_daily_state` 仅新增字段，旧数据向后兼容。

---

## 9. 建议实施顺序

1. **数据层**：`focusLog` / `pomoPref` 字段 + 读写辅助。
2. **番茄钟 UI**：任务卡「专注」入口 + 悬浮小环 + 计时逻辑 + 完成流程（自动 +1 / 通知 / 写历史 / 自动休息）+ 停止。
3. **周报趋势**：「本月进度」视图扩展 + 30 天达标率折线 + 7 天专注柱状 + 本周小结卡 + 空态。
4. **校验 + 文档同步**：`node --check`、手动验证、三处文档同步。

---

## 10. 开放项 / 可选增强（不阻塞本轮）

- 进行中会话刷新后恢复（sessionStorage）。
- `todoLog`：记录待办完成，使周报可含「完成待办数」。
- 周维度之外增加「月维度」汇总切换。
